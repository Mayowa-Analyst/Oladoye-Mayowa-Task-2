# 📊 Retail Sales Performance Analysis (Task 1)

## 📌 Project Overview
This project focuses on the end-to-end analysis of a retail dataset containing 1,200 unique orders for **DecodeLabs Task 1**. The goal was to clean the raw data, perform descriptive statistical analysis, and use pivot tables to uncover key sales, marketing, and operational trends.

---

## 🛠️ Data Cleaning Process
Before running any analysis, the raw data was cleaned to ensure accurate results:
* **Fixed Missing Data:** Filled missing coupon code fields with `"No Coupon"`.
* **Standardized Formats:** Converted all mixed date formats into a uniform structure.
* **Text Cleanup:** Applied `TRIM` to remove accidental spaces and forced text fields to consistent casing.

---

## 📈 Key Statistical Metrics
Using Excel's Data Analysis Toolpak, a summary was generated across the 1,200 orders:

* **Total Revenue:** $1,264,761.96
* **Average Order Value:** $1,053.97
* **Average Items per Cart:** ~5.5 items
* **Highest Single Order:** $3,456.40

---

## 🔍 Top Business Insights

### 1. Sales & Products
* **Top Earners:** **Chairs** ($195,620.11) and **Printers** ($195,612.61) generated the highest revenue.
* **Volume Leader:** **Printers** were the most frequently purchased item (181 units).

### 2. Marketing Channels
* **Instagram** was the most successful acquisition channel, driving **$275,285.45** in sales, closely followed by Email marketing ($261,808.55).

### 3. Timeline & Seasonality
* **Peak Year:** 2023 was the highest-earning year with **$552,643.24**.
* **Peak Month:** **June** saw a massive seasonal spike, bringing in **$170,616.13** in a single month.

### 4. Operational Warning
* **High Returns/Cancellations:** Combined, **497 orders** were either cancelled or returned. This represents a significant revenue leak that requires operational review.
